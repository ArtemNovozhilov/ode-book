1.2.1Definitions

Definition 1.5. An ordinary differential equation is an equation of the form \begin{equation} F(t,x,x',\ldots,x^{(k)})=0, \tag{1.2}\end{equation} for a given \(F\colon U\subseteq \R^{k+2}\longrightarrow \R\). A solution to (1.2) on the interval \(I=(a,b)\) is a function1 \(\phi\in \mathcal C^{(k)}(I;\R)\) such that \(\bigl(t,\phi(t),\phi'(t),\ldots,\phi^{(k)}(t)\bigr)\in U\) for all \(t\in I\) and (1.2) turns into the identity \[ F\bigl(t,\phi(t),\phi'(t),\ldots,\phi^{(k)}(t)\bigr)=0\quad \text{for all }t\in I. \] The order of (1.2) is the order of the highest derivative in it.

In this course I will always assume that (1.2) can be rewritten as \begin{equation} x^{(k)}=f(t,x,x',\ldots,x^{(k-1)}), \tag{1.3}\end{equation} which frequently can be done, at least locally, thanks to the implicit function theorem: it suffices that \(\partial F/\partial x^{(k)}\neq 0\) at the point under consideration (in case you would like to refresh your memory on the exact statement of this theorem, you can find it in the appendix to Chapter 2 of these notes).

Any equation of the form (1.3) can be written as an equivalent system of \(k\) first-order ODE. To wit, let \[ y_1=x,\quad y_2=x',\quad \ldots,\quad y_k=x^{(k-1)}, \] then I have \begin{align*} \dot y_1&=y_2,\\ \dot y_2&=y_3,\\ &\ldots\\ \dot y_k&=f(t,y_1,\ldots,y_k). \end{align*} Therefore, it is convenient (for theoretical, as well as for numerical purposes) to concentrate attention on the systems of ODE of the form \begin{equation} \dot{\bs x}=\bs f(t,\bs x),\quad \bs x(t)\in X\subseteq \R^k,\quad \bs f\colon J\times X\longrightarrow \R^k, \tag{1.4}\end{equation} where \(J\subseteq \R\) is an interval of the real line, on which the right-hand side of (1.4) is defined with respect to \(t\). For now \(X\) is an arbitrary subset of \(\R^k\); starting with the existence and uniqueness theorems, I will assume that \(X\) is open. If the right-hand side of (1.4) does not depend on \(t\) explicitly, then the system is called autonomous. Any non-autonomous system can be written as an autonomous one by adding one more equation and one more variable. For example, a scalar non-autonomous equation \(\dot x=f(t,x)\) with the initial condition \(x(t_0)=x_0\) can be turned into a system of two first-order autonomous equations \begin{align*} \dot x_1&=f(x_2,x_1), \\ \dot x_2&=1. \end{align*} Note that this procedure can yield nonlinear problems although the original one was linear2: for instance, \(\dot x=tx\) turns into \(\dot x_1=x_2x_1\), \(\dot x_2=1\).

Example 1.6. Let3 \[ \dot x=f(t),\quad f\in \mathcal C(J). \] By the fundamental theorem of calculus, I have \[ x(t)=x_0+\int_{t_0}^t f(\tau)\D\tau, \] if the solution satisfies the initial condition \(x(t_0)=x_0\). Sometimes it is more convenient to use the indefinite integral, and the general solution will be \[ x(t)=\int f(t)\D t+C, \] where \(C\) is an arbitrary constant.

Example 1.7. Consider the following ODE \[ \dot x=ax,\quad a\in \R. \] The exponential \(t\mapsto Ce^{at}\), where \(e=2.7182818284\ldots\), is a solution, which is checked by direct substitution. In fact, there are no other solutions:

Lemma 1.8. Any solution to \(\dot x=ax\) is given by \(t\mapsto Ce^{at}\).

Proof. Let \(u\) be a solution to \(\dot x=ax\) on an interval \(I\). Consider \[ (u(t)e^{-at})'=u'(t)e^{-at}-au(t)e^{-at}=au(t)e^{-at}-au(t)e^{-at}=0. \] Since \(I\) is an interval, a function with zero derivative on \(I\) is constant, hence \[ u(t)e^{-at}=C\Longleftrightarrow u(t)=Ce^{at},\quad t\in I. \] ■

In case I have the initial condition \(x(t_0)=x_0\), the solution is \(t\mapsto x_0e^{a(t-t_0)}\).

Exercise 1.2. Let \[ x^{(k)}=f(x,x',\ldots,x^{(k-1)}) \] be an autonomous equation. Show that if \(t\mapsto\phi(t)\) is a solution, then so is \(t\mapsto \phi(t-t_0)\), where \(t_0\) is an arbitrary constant.

Exercise 1.2 shows that for autonomous equations (and hence for autonomous systems) I can always take the initial conditions at \(t=0\); other solutions can be obtained by translations.

Exercise 1.3. Find the general solution to \[ \dot x=0. \] By analyzing this solution argue that the presence of interval \(I\) in Definition 1.5 is necessary.

Exercise 1.4. Does there exist a solution to the problem \[ \dot x=\begin{cases} \phantom{-}1,&x<0,\\ -1,&x\geq 0, \end{cases} \] with the initial condition \(x(0)=0\)? Justify your answer. (If this problem is a little confusing at first sight, reading the next section may help.)

Exercise 1.5. In all the examples I gave so far the general solution to an ODE depended on arbitrary constants whose number coincided with the order of the equation. This is true for most examples but not for all. Can you provide an example of an ODE that has no solution at all?

Remark 1.9. In many textbooks a somewhat less precise definition of an ODE is given. Here is one example: “Let \(f(x)\) define a function of \(x\) on an interval \(I\colon a<x<b\). By an ODE we mean an equation involving \(x\), the function \(f(x)\) and one or more of its derivatives.” This looks like a reasonable definition, however, it classifies the equation \[ f'(x)=f(f(x)) \] as an ODE, which, strictly speaking, is incorrect. So I urge students to be careful when trying to come up with a good definition. (Can you attempt to solve the equation given in this remark? That is a good Friday evening exercise.)

1.2.2Geometric interpretation of the first-order scalar ODE

It is convenient to have at hand a geometric interpretation of the solutions to first-order scalar ODE of the form \begin{equation} \dot x=f(t,x),\quad x(t)\in X\subseteq \R,\quad f\colon J\times X\longrightarrow \R. \tag{1.5}\end{equation}

Consider in \(J\times X\) the direction field defined by the function \((t,x)\mapsto \theta(t,x)\). Imagine that through each point \((t,x)\) a specific straight line is passing (i.e., each point has a direction), then \(\theta(t,x)\in[0,\pi)\) is the angle between the line through \((t,x)\) and the \(t\)-axis; this literally means that at each point \((t,x)\in J\times X\) the slope (direction) is given by \(\tan\theta(t,x)\) (note that I include vertical directions).

A smooth curve \(\tau\mapsto (t(\tau),x(\tau))\) is said to be an integral curve of the direction field \(\theta\) on the interval \(\tau\in(a,b)\), if \(t,x\in \mathcal C^{(1)}(a,b)\), there is no \(\tau\) such that \(t'(\tau)=x'(\tau)=0\), and \[ \frac{x'(\tau)}{t'(\tau)}=\tan \theta(t(\tau),x(\tau)),\quad \tau\in(a,b), \] which means that the tangent vector to an integral curve at each point \((t(\tau),x(\tau))\) is given by the direction \(\theta(t(\tau),x(\tau))\) (see Fig. 1.1). To include the vertical direction, the last equality is considered true if \(t'(\tau)=0\) and \(\theta(t(\tau),x(\tau))=\frac{\pi}{2}\) simultaneously. The next lemma shows that having a direction field \(\theta\) is the same (well, almost; see the remark after the lemma) as having the ODE (1.5) with \(f(t,x)=\tan \theta(t,x)\).

Lemma 1.10. A curve \(\tau\mapsto(t(\tau),x(\tau))\) is an integral curve of the direction field \((t,x)\mapsto \theta(t,x)\), with \(\theta\neq \pi/2\), if and only if it can locally be written as \(t\mapsto x(t)\), and \(x\) solves (1.5) with \(f(t,x)=\tan\theta(t,x)\).

Proof. Let \(t\mapsto x(t)\) solve (1.5) on \(t\in I\). Consider the curve \(\tau\mapsto(\tau,x(\tau)),\,\tau\in I\). It is \(\mathcal C^{(1)}(I)\) since it is a solution to an ODE, \(t'(\tau)=\tau'=1\), so both components cannot be zero simultaneously, and \[ \frac{x'(\tau)}{t'(\tau)}=x'(\tau)=f(\tau,x(\tau))=\tan\theta(\tau,x(\tau)), \] hence it is an integral curve.

Conversely, let \(\tau\mapsto(t(\tau),x(\tau))\) be an integral curve with \(t'(\tau)\neq 0\). This means, by the inverse function theorem, that our curve locally can be represented as a graph of \(t\mapsto x(t)\), and \(x\in\mathcal C^{(1)}\). By the same theorem, \[ x'(t)=\frac{x'(\tau)}{t'(\tau)}=\tan \theta(t(\tau),x(\tau))=f(t,x), \] i.e., it solves (1.5) as required. ■

Remark 1.11. I showed only that if I have a solution to an ODE then this solution is an integral curve; and if I have an integral curve of a direction field without vertical directions then it solves an ODE. This omission of vertical directions can be dealt with as follows.

Together with \[ \frac{\D x}{\D t}=f(t,x) \] consider \[ \frac{\D t}{\D x}=h(t,x), \] where \(h(t,x)=\cot \theta(t,x)\). Then, clearly (think this out!), the direction field \(\theta\) is equivalent to the pair of ODE, for which \(f(t,x)=1/h(t,x)\) at those points \((t,x)\) at which both \(f\) and \(h\) are defined. Moreover, the vertical directions are treated by switching to the second ODE.

For instance, if you consider an ODE \[ \dot x=-\frac{t}{x}\,, \] its right-hand side is not defined for \(x=0\). If, however, I’d like to treat it geometrically and consider the corresponding direction field, it is actually defined at every point \((t,x)\neq (0,0)\), and the integral curves are the circles with the center \((0,0)\); the direction on the \(t\)-axis (e.g., \(x=0\)) is vertical at every point.

Using Lemma 1.10 I can state the following: To geometrically solve (1.5) amounts to finding integral curves belonging to the direction field defined by \(f\). There are infinitely many such curves. To geometrically solve the initial value problem (IVP from now on) with \(x(t_0)=x_0\) amounts to finding an integral curve belonging to the direction field and passing through the point \((t_0,x_0)\). In the following I will use the terms “solutions to ODE” and “integral curves” interchangeably.

Exercise 1.6. Sketch several integral curves of the differential equations \[ (a)\quad \dot x=\frac{tx}{{\lvert tx\rvert }}\,,\quad (b)\quad \dot x=\frac{{\lvert t+x\rvert }}{t+x}\,,\quad (c) \quad \dot x=-\frac{t+{\lvert t\rvert }}{x+{\lvert x\rvert }}\,,\quad (d)\quad \dot x=\begin{cases} 0,&t\neq x,\\ 1,&t=x. \end{cases} \]

Exercise 1.7. Sketch several integral curves of the differential equation \[ \dot x=\frac{x-t}{x+t}\,. \] (Hint: If you are doing it without any help from a computer, an efficient way is to consider the so-called isoclines, i.e., the curves of the constant slope, which are defined by \(f(t,x)=\tan \theta\) for the given angle \(\theta\).)

Can two integral curves cross? Obviously, no (for reasonable, say, continuous, \(f\)), because this would mean that at the same point I have two different slopes. However, two integral curves in principle can be tangent to each other at some point \((t_0,x_0)\). In general, from an applied point of view, this situation is not pleasant, since it means that more than one solution is defined by the initial conditions and the given mathematical model. Therefore, it is important to identify conditions under which only one integral curve passes through each point.

Note that the direction field defined by \(f\) in Example 1.6 does not depend on \(x\) and is therefore invariant with respect to translations along the \(x\)-axis. This fact is exactly what has allowed me to integrate my differential equation in Example 1.6: at each point \(t\) I have the slope \(f(t)\) and my task is to find a function with this slope at \(t\).

What if the direction field is invariant with respect to translations along the \(t\)-axis? This means that this direction field does not depend on \(t\) explicitly (it is autonomous). Now, since the slope at the point \((t,x)\) is equal to the tangent of the angle \(\theta\) between the \(t\)-axis and the line through this point (\(\tan \theta=f(x)\)), to find the tangent of the angle between the same line and the \(x\)-axis amounts to finding \(\tan\varphi=\tan(\pi/2-\theta)\) (see Fig. 1.2, left panel). I have \[ \tan(\pi/2-\theta)=\frac{1}{\cot(\pi/2-\theta)}=\frac{1}{\tan \theta}=\frac{1}{f(x)}\,. \] Therefore, to integrate an autonomous direction field (i.e., invariant with respect to translations along the \(t\)-axis), I need to evaluate one integral (compare it with Example 1.6 and Remark 1.11) \begin{equation} t=t_0+\int_{x_0}^x\frac{\D s}{f(s)}\,, \tag{1.6}\end{equation} which gives the solution to \(\dot x=f(x)\) in an implicit form.

The reasoning above can be summarized as follows.

Lemma 1.12. Let \(\dot x=f(x),\,x(t)\in X\subseteq \R,\,f\in\mathcal C(X),\,f(x)\neq 0\) for \(x\in X\). Then the solution to \(\dot x=f(x),\,x(t_0)=x_0\) exists and is unique for any \(x_0\in X\), and is given by (1.6).

Remark 1.13. The usual way to derive (1.6) in introductory ODE courses is to write \[ \frac{\D x}{\D t}=f(x), \] manipulate \[ \frac{\D x}{f(x)}=\D t, \] and integrate \[ \int_{x_0}^x\frac{\D s}{f(s)}=\int_{t_0}^t\D\tau, \] to recover (1.6). This procedure treating the derivative as a fraction does not lead to any errors, but may be confusing for those who try to understand the logic behind every step of the reasoning, because definitely the usual derivative is not a fraction.

A better, and completely rigorous, approach to integrating the equation \(\dot x=f(x)\) mechanically is to rearrange it as \(\frac{\dot x}{f(x)}=1\), assuming \(f(x)\neq 0\), and to integrate both sides of this last equality with respect to variable \(t\): \[ \int_{t_0}^t\frac{\dot x(\tau)}{f(x(\tau))}\D \tau=\int_{t_0}^t\D \tau, \] and now make a substitution \(s= x(\tau)\), which leads to (1.6) \[ \int_{x_0}^x \frac{\D s}{f(s)}=t-t_0. \]

Remark 1.14. Treating expressions like \(\frac{\D x}{\D t}\) as fractions quite often yields correct results. Think, for instance, about the chain rule for the composite function \(t\mapsto f(u(t))\): \[ \frac{\D f}{\D t}=\frac{\D f}{\D u}\frac{\D u}{\D t}\,. \] It should be stressed, however, that unless you clearly understand what \(\D x\) and \(\D t\) mean, and what it means to divide one by the other one, you should avoid “intuitively plausible” arithmetic with these quantities. Here is, for instance, an example where simple canceling of identical terms leads to a senseless result: Consider an implicitly defined function \(F(x,y)=0\). Then, as it is shown in many calculus books, assuming that \(\frac{\partial F}{\partial y}\neq 0\) at a given point, \[ \frac{\D y}{\D x}=-\frac{\frac{\partial F}{\partial x}}{\frac{\partial F}{\partial y}}\,, \] which will not make any sense if you cancel “\(\partial F\).”

If you still insist on treating \(\D x\) and \(\D t\) separately, then probably the most natural interpretation for them that allows such treatment is to assume that \(\D x\) and \(\D t\) are differential forms, but this would take us too far away from the main line of our course.

Using reasoning similar to the above, I find the following.

Lemma 1.15. Consider the ODE \begin{equation} \dot x=f_1(t)f_2(x),\quad t\in J,\,x(t)\in X,\, f_1\in \mathcal C(J),\,f_2\in \mathcal C(X). \tag{1.7}\end{equation} Assume that \(f_2(x)\neq 0\) for any \(x\in X\). Then for any point \((t_0,x_0)\in J\times X\) there exists a unique integral curve passing through this point. This curve can be found with two integrals \[ \int_{x_0}^x\frac{\D s}{f_2(s)}=\int_{t_0}^t f_1(\tau)\D \tau. \]

Exercise 1.8. Prove Lemma 1.15.

What if there is an \(\hat{x}\in X\) such that \(f(\hat{x})=0\) in \(\dot x=f(x)\) or \(f_2(\hat{x})=0\) in (1.7)? Note that in this case the function \(t\mapsto \hat{x}\) is a solution (it satisfies the equation). Then I am tempted to generalize, e.g., Lemma 1.12 in the following (incorrect!) way:

Let \(\dot x=f(x),\,x(t)\in X\subseteq \R,\,f\in\mathcal C(X)\). Then for any point \((t_0,x_0)\in \R\times X\) the solution to \(\dot x=f(x)\) passing through this point exists and is unique. It is given by (1.6) if \(f(x_0)\neq 0\) or by \(t\mapsto x_0\) if \(f(x_0)=0\).

Example 1.16 (Non-uniqueness of solutions to an IVP). Consider the following IVP \[ \dot x=x^{1/3},\quad x(0)=0. \] First I notice that \(t\mapsto 0\) is a solution. However, using (1.6) I find that \[ t\mapsto \begin{cases} 0, &t\leq 0,\\[3pt] \displaystyle \left(\frac{2t}{3}\right)^{3/2}, &t>0, \end{cases} \] is also a solution passing through the point \((0,0)\)! Moreover, the functions defined by \[ t\mapsto \begin{cases} 0, &t\leq a,\\[3pt] \displaystyle \pm\left(\frac{2(t-a)}{3}\right)^{3/2}, &t>a, \end{cases} \] are also solutions passing through \((0,0)\) for any constant \(a\geq 0\) (check this statement).

By carefully analyzing the reason why the solution in the last example is not unique (do the integration step by step!), I conclude that a correct statement should be the following.

Lemma 1.17. Let \(\dot x=f(x),\,x(t)\in X\subseteq \R,\,f\in\mathcal C(X)\). Then for any point \((t_0,x_0)\in \R\times X\) the solution, given by (1.6), passing through this point, exists and is unique if \(f(x_0)\neq 0\). If \(f(x_0)=0\) and the improper integral \[ \int_{x_0}^x\frac{\D s}{f(s)} \] diverges, then the unique solution for \(x(t_0)=x_0\) is given by \(t\mapsto x_0\).

Remark 1.18. I note that the improper integral in Lemma 1.17 must diverge on both sides of \(x_0\), so technically, it is two improper integrals.

Exercise 1.9. Show that all the solutions to \(\dot x=f(x),\,f\in \mathcal C^{(1)}\) are monotone functions.

Exercise 1.10. Prove Lemma 1.17.

Note that a sufficient condition for this integral to diverge is that \(f\) is continuously differentiable around \(x=x_0\) (why?). This can be stated as follows.

Lemma 1.19. Consider (1.7) and assume that \(f_1\in \mathcal C(J)\) and \(f_2\in \mathcal C^{(1)}(X)\). Then for any point \((t_0,x_0)\in J\times X\) there exists a unique integral curve passing through this point.

It turns out that a very similar statement can be formulated in much more general situations (see the next chapter).

Before finishing this section, I would like to remark that I never discussed the interval of existence of my solutions. This is an important point, as the following example shows.

Example 1.20. Consider \[ \dot x=x^2. \] This equation satisfies the conditions of Lemma 1.17 everywhere in \(\R\) with respect to both \(t\) and \(x\), and therefore for any initial conditions \((t_0,x_0)\) there must be a unique integral curve through this point. It is \(t\mapsto 0\) if \(x_0=0\) and \[ t\mapsto \frac{1}{C-t}\,, \] for an arbitrary constant \(C\). If \(t\to C\) then my solution approaches infinity in a finite time interval (it blows up). Therefore, the solution is defined on some smaller interval \((-\infty,C)\subseteq \R\) (for \(x_0>0\)) (see Fig. 1.2, the right panel, for the direction field defined by \((t,x)\mapsto x^2\)).
