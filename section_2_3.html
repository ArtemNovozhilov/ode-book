A basic mathematical structure that underlies most of modern mathematics is a set1. To make progress in describing various models, I need to add additional structures to the sets I deal with. For example, a topological structure implies that I can talk about open and closed sets, and can introduce the notions of convergence and continuity. Arguably, the simplest way to introduce a topological structure (but not the most general one!) is to consider a metric, or a distance function, on the given set.

In this section I collect only what will be used in the proof of the existence and uniqueness theorem: complete metric spaces, the space of continuous functions with the uniform distance, the fact that closed subsets of complete metric spaces are complete, and the contraction mapping principle.

2.3.1Metric spaces

Definition 2.9. A metric space is a pair \((\mathcal M,\varrho)\), where \(\mathcal M\) is the underlying set2, and \(\varrho \colon \mathcal M\times \mathcal M\longrightarrow \R\) is a function that gives a “distance” between any two points \(x,y\) of \(\mathcal M\) and satisfies the following properties: \begin{align*} \varrho(x,y)&\geq 0,\quad \varrho(x,y)=0\Longleftrightarrow x=y,\quad\text{\emph{(}\textit{positivity}\emph{)}}\\ \varrho(x,y)&=\varrho(y,x),\quad\text{\emph{(}\textit{symmetry}\emph{)}}\\ \varrho(x,y)&\leq \varrho(x,z)+\varrho(z,y).\quad\text{\emph{(}\textit{triangle inequality}\emph{)}} \end{align*}

These are the natural properties of a distance that we are used to in the Euclidean space \(\R^3\) with the standard distance \[ \varrho(\bs x,\bs y)=\sqrt{(x_1-y_1)^2+(x_2-y_2)^2+(x_3-y_3)^2},\quad \bs x,\bs y\in \R^3. \]

Using the distance function I immediately get the notion of a convergent sequence, which turns sequences of possibly quite abstract objects into our familiar numerical sequences that converge to zero.

Definition 2.10. A sequence \((x_n)_{n=1}^\infty\) of points of the metric space \((\mathcal M,\varrho)\) is said to converge to \(x\in \mathcal M\), written as usual \[ \lim_{n\to\infty} x_n=x,\quad \text{or}\quad x_n\to x, \] if for any \(\epsilon>0\) there exists \(N=N(\epsilon)\) such that for all \(n\geq N\) \[ \varrho(x_n,x)< \epsilon. \]

Exercise 2.3. Prove that a convergent sequence has only one limit.

Using the distance function I can also define open and closed sets. To wit, let \[ B_\delta(a)=\{x\in \mathcal M\colon \varrho(a,x)<\delta\} \] be the ball with center \(a\) and radius \(\delta>0\), or a \(\delta\)-neighborhood of the point \(a\).

Definition 2.11. A set \(U\subseteq \mathcal M\) is open in the metric space \((\mathcal M,\varrho)\) if for each point \(x\in U\) there exists a ball \(B_\delta(x)\) such that \(B_\delta(x)\subseteq U\). A set \(A\subseteq \mathcal M\) is closed if its complement \(\mathcal M\setminus A\) is open.

In analysis (specifically, in the situation when I work in a metric space) it is almost always much more convenient to work with an equivalent characterization of closed sets.

Lemma 2.12. A set \(A\subseteq \mathcal M\) is closed if and only if for any convergent sequence \((x_n)\), \(x_n\to x\), where all \(x_n\in A\), it follows that \(x\in A\).

Exercise 2.4. Prove Lemma 2.12. Prove that a ball is an open set. Is \(\mathcal M\) open? Is it closed? What about \(\emptyset\)?

Here are several examples of metric spaces.

Example 2.13. \(\mathcal M=\R\) with \(\varrho(x,y)={\lvert x-y\rvert }\).

Example 2.14. \(\mathcal M=\R^k\) with the Euclidean distance \[ \varrho_2(\bs x,\bs y)=\sqrt{\sum_{i=1}^k (x_i-y_i)^2}\,, \] or with the distance \[ \varrho_\infty(\bs x,\bs y)=\max_{i}{\lvert x_i-y_i\rvert }. \] Since \(\varrho_\infty(\bs x,\bs y)\leq \varrho_2(\bs x,\bs y)\leq \sqrt{k}\,\varrho_\infty(\bs x,\bs y)\), a sequence converges with respect to \(\varrho_2\) if and only if it converges with respect to \(\varrho_\infty\), and in both cases convergence means the usual coordinatewise convergence.

Example 2.15. Any set \(\mathcal M\) with the discrete metric: \(\varrho(x,y)=1\) if \(x\neq y\) and \(\varrho(x,x)=0\). Here every set is both open and closed, and only the sequences that are eventually constant converge.

Example 2.16. Let \(\mathcal M=\mathcal C[a,b]\) be the set of continuous functions \(x\colon[a,b]\longrightarrow \R\). Since a continuous function attains its maximum on a closed interval, I can define \[ \varrho_\infty(x,y)=\max_{t\in[a,b]}{\lvert x(t)-y(t)\rvert }. \] A different metric on the same set is given by \[ \varrho_1(x,y)=\int_a^b{\lvert x(t)-y(t)\rvert }\D t. \]

Exercise 2.5. Check that \(\varrho_2\), \(\varrho_\infty\), \(\varrho_1\), and the discrete metric satisfy the axioms of a metric space.

Example 2.17. If \((\mathcal M,\varrho)\) is a metric space and \(Y\subseteq \mathcal M\) is any subset, then \((Y,\varrho)\), where \(\varrho\) is restricted to \(Y\times Y\), is also a metric space. Note that \(Y\) does not have to have any additional structure. For instance, the set of functions \(x\in\mathcal C[a,b]\) satisfying \({\lvert x(t)\rvert }\leq 1\) for all \(t\in[a,b]\) is a metric space with the distance \(\varrho_\infty\), although the sum of two such functions does not have to belong to this set.

Consider now a mapping \(g\colon \mathcal M_1\longrightarrow \mathcal M_2\) between two metric spaces \((\mathcal M_1,\varrho_1)\) and \((\mathcal M_2,\varrho_2)\).

Definition 2.18. The mapping \(g\) is continuous at the point \(x_0\) if for any \(\epsilon>0\) there exists a \(\delta=\delta(x_0,\epsilon)>0\) such that for any \(x\in \mathcal M_1\) for which \(\varrho_1(x,x_0)< \delta\) I have \[ \varrho_2(g(x),g(x_0))< \epsilon. \] \(g\) is continuous if it is continuous at each point of \(\mathcal M_1\).

The connection between continuity and convergent sequences can be stated as follows.

Lemma 2.19. A mapping \(g\colon\mathcal M_1\longrightarrow\mathcal M_2\) is continuous if and only if \[ g(\lim x_n)=\lim g(x_n) \] for any convergent sequence \((x_n)\) in \((\mathcal M_1,\varrho_1)\). In other words, a mapping is continuous if and only if it preserves convergent sequences.

Exercise 2.6. Prove Lemma 2.19.

2.3.2Uniform convergence

Let me now recall the notions of pointwise and uniform convergence.

The sequence of functions \((x_n)_{n=1}^\infty\) converges pointwise on \([a,b]\) to a function \(x\) if, given any point \(t\in[a,b]\) and any \(\epsilon>0\), there exists \(N(\epsilon,t)\) such that for any \(n\geq N\) I have \({\lvert x_n(t)-x(t)\rvert }< \epsilon\). Note that different \(t\) may require different \(N\). A sequence of functions \((x_n)_{n=1}^\infty\) converges uniformly to \(x\) if for any \(\epsilon>0\) there exists \(N(\epsilon)\) such that for any \(n\geq N\) and any \(t\in[a,b]\) I have \({\lvert x_n(t)-x(t)\rvert }<\epsilon\). Note that now \(N\) works for any \(t\). Since \[ {\lvert x_n(t)-x(t)\rvert }\leq \max_{t\in [a,b]}{\lvert x_n(t)-x(t)\rvert }=\varrho_\infty(x_n,x), \] for continuous \(x_n\) and \(x\) uniform convergence is exactly the convergence in the metric space \((\mathcal C[a,b],\varrho_\infty)\).

One of the most important properties of uniform convergence can be stated as follows.

Lemma 2.20. If the sequence \((x_n)_{n=1}^\infty\) converges uniformly to \(x\) and each \(x_n\in \mathcal C[a,b]\), then \(x\in\mathcal C[a,b]\).

Proof. I need to prove that \(x\) is continuous at any \(t\in[a,b]\), i.e., for any \(\epsilon>0\) I need to find \(\delta>0\) such that \({\lvert x(t)-x(s)\rvert }< \epsilon\) for \({\lvert t-s\rvert }< \delta\).

Pick any \(\epsilon>0\). Since \((x_n)_{n=1}^\infty\) converges uniformly, I can always find \(n\) such that for any \(s\in[a,b]\) \[ {\lvert x_n(s)-x(s)\rvert }<\frac{\epsilon}{3}\,. \] Since \(x_n\) is continuous at \(t\), for given \(\epsilon/3\) I can pick \(\delta>0\) such that \[ {\lvert x_n(t)-x_n(s)\rvert }< \frac \epsilon 3 \] for \({\lvert t-s\rvert }<\delta\). Now \[ {\lvert x(t)-x(s)\rvert }\leq {\lvert x(t)-x_n(t)\rvert }+{\lvert x_n(t)-x_n(s)\rvert }+{\lvert x_n(s)-x(s)\rvert }< \frac{\epsilon}{3}+\frac{\epsilon}{3}+\frac{\epsilon}{3}=\epsilon. \] ■

2.3.3Complete metric spaces

To determine whether a given sequence converges using the definition requires knowing its limit. In practical situations, however, this limit is of course not known and cannot be reliably guessed. To be able to make conclusions about convergence of a given sequence, one needs to speak about a very important property of metric spaces — completeness.

Definition 2.21. A sequence \((x_n)_{n=1}^\infty\) in a metric space \((\mathcal M,\varrho)\) is called fundamental or Cauchy if for any \(\epsilon>0\) there exists \(N(\epsilon)\) such that for any \(n,m\geq N\) \[ \varrho(x_n,x_m)<\epsilon. \]

Definition 2.22. A metric space \((\mathcal M,\varrho)\) is called complete if every fundamental sequence converges.

Exercise 2.7. Prove that every convergent sequence is fundamental.

The converse is not true in general. The real line \(\R\) with \(\varrho(x,y)={\lvert x-y\rvert }\) is complete (this is one of the basic properties of real numbers, see any analysis book), whereas the set of rational numbers with the same distance is not: the decimal approximations \(1,\ 1.4,\ 1.41,\ 1.414,\ldots\) of \(\sqrt 2\) form a fundamental sequence that has no rational limit. Since convergence in \(\R^k\) is coordinatewise (Example 2.14), the space \(\R^k\) is also complete.

Lemma 2.23. The metric space \((\mathcal C[a,b],\varrho_\infty)\) is complete.

Proof. Let \((x_n)_{n=1}^\infty\) be a fundamental sequence. Since for each fixed \(t\in[a,b]\) the sequence \((x_n(t))_{n=1}^\infty\) is fundamental in \(\R\), and \(\R\) is complete, there exists at least a pointwise limit \[ \lim_{n\to\infty}x_n(t)=x(t),\quad t\in[a,b]. \] Now fix \(\epsilon>0\). Since \((x_n)\) is fundamental, there exists \(N(\epsilon)\) such that for \(m,n\geq N\) and each \(t\in[a,b]\) \[ {\lvert x_m(t)-x_n(t)\rvert }\leq \varrho_\infty(x_m,x_n)<\epsilon, \] where \(N\) does not depend on \(t\). It is possible to go to the limit \(n\to\infty\) here since the absolute value is continuous. Taking the limit I conclude that \[ {\lvert x_m(t)-x(t)\rvert }\leq \epsilon,\quad m\geq N, \] for all \(t\in[a,b]\), which exactly means uniform convergence. Since all \(x_m\) are continuous, the limit \(x\) is also continuous by Lemma 2.20, and hence \(\varrho_\infty(x_m,x)\to 0\). ■

The choice of the metric is important, as the following example shows.

Example 2.24. Consider the sequence \((x_n)_{n=1}^\infty\) in \(\mathcal C[-1,1]\) defined by \[ x_n(t)=\begin{cases}-1,&-1\leq t\leq -\frac 1n\,,\\ nt,&-\frac 1n<t<\frac 1n\,,\\ \phantom{-}1,& \frac 1n\leq t\leq 1. \end{cases} \] The sequence \((x_n)_{n=1}^\infty\) is fundamental in \((\mathcal C[-1,1],\varrho_1)\) (check it!). Consider also the discontinuous function \[ x(t)=\begin{cases} -1,&-1\leq t\leq 0,\\ \phantom{-}1,&0<t\leq 1, \end{cases} \] for which \(\int_{-1}^1{\lvert x_n(t)-x(t)\rvert }\D t=1/n\to 0\). If \(x_n\to y\) in \((\mathcal C[-1,1],\varrho_1)\) for some continuous \(y\), then \[ \int_{-1}^1{\lvert y(t)-x(t)\rvert }\D t\leq \varrho_1(y,x_n)+\int_{-1}^1{\lvert x_n(t)-x(t)\rvert }\D t\to 0, \] hence \(y(t)=-1\) for \(t\in[-1,0)\) and \(y(t)=1\) for \(t\in(0,1]\) (why?), which is impossible for a continuous \(y\). Therefore, \((\mathcal C[-1,1],\varrho_1)\) is not complete.

Finally, I will need the following simple fact.

Lemma 2.25. A closed subset \(A\) of a complete metric space \((\mathcal M,\varrho)\) is itself a complete metric space with the same distance \(\varrho\).

Proof. Let \((x_n)\) be a fundamental sequence in \(A\). Then it is fundamental in \(\mathcal M\), and since \(\mathcal M\) is complete, \(x_n\to x\in\mathcal M\). Since \(A\) is closed, \(x\in A\) by Lemma 2.12. ■

2.3.4Normed vector spaces

In what follows I will mostly be working in metric spaces that also have the structure of a linear (vector) space over \(\R\), i.e., I can add their elements and multiply them by real numbers, and the usual rules of linear algebra hold. The basic example of a real vector space is \(\R^k\), where the vectors3 are \(\bs x=(x_1,\ldots,x_k)^\top\); another example is \(\mathcal C[a,b]\) with pointwise operations. For such spaces the distance is usually given by a norm, which unites both the topological (metric) and algebraic properties.

Definition 2.26. Let \(\mathcal V\) be a real vector space. A function \({\lVert \cdot\rVert }\colon \mathcal V\longrightarrow\R\) is called a norm in \(\mathcal V\) if for any \(x,y\in \mathcal V\) and \(\alpha\in\R\) it satisfies \begin{align*} {\lVert x\rVert }&\geq 0,\,{\lVert x\rVert }=0\Longleftrightarrow x=0,\quad\text{\emph{(}\textit{positivity}\emph{)}}\\ {\lVert \alpha x\rVert }&={\lvert \alpha\rvert }{\lVert x\rVert },\quad\text{\emph{(}\textit{homogeneity}\emph{)}}\\ {\lVert x+y\rVert }&\leq {\lVert x\rVert }+{\lVert y\rVert }.\quad\text{\emph{(}\textit{triangle inequality}\emph{)}} \end{align*} A vector space \(\mathcal V\) with a norm defined on it is called a normed vector space and denoted \((\mathcal V,{\lVert \cdot\rVert })\) or simply \(\mathcal V\) if no confusion arises.

Every normed space has the natural metric \[ \varrho(x,y)={\lVert x-y\rVert }, \] and therefore everything said above about metric spaces applies to normed spaces. For example, \(x_n\to x\) in \((\mathcal V,{\lVert \cdot\rVert })\) if the sequence of real numbers \({\lVert x_n-x\rVert }\) converges to zero.

Definition 2.27. A normed vector space that is complete with respect to the metric \(\varrho(x,y)={\lVert x-y\rVert }\) is called a Banach space.

Exercise 2.8. Show that \[ {\Bigl\lvert {\lVert x\rVert }-{\lVert y\rVert }\Bigr\rvert }\leq {\lVert x-y\rVert }. \]

Exercise 2.9. Let \((\mathcal V,{\lVert \cdot\rVert })\) be a normed vector space. Show that the norm, vector addition, and multiplication by scalars are continuous.

Example 2.28. Let \(\mathcal V=\R^k\). The distances in Example 2.14 are generated by the norms \[ {\lVert \bs x\rVert }_2=\sqrt{\sum_{i=1}^k x_i^2}\,,\qquad {\lVert \bs x\rVert }_\infty=\max_{i}{\lvert x_i\rvert }. \]

Exercise 2.10. Prove that \({\lVert \cdot\rVert }_2\) is a norm. (Hint: First prove the Cauchy–Schwarz inequality \({\lvert \bs x\cdot\bs y\rvert }\leq {\lVert \bs x\rVert }_2 {\lVert \bs y\rVert }_2\), where \(\bs x\cdot\bs y\coloneqq\sum_{i=1}^kx_iy_i\), and use \({\lVert \bs x\rVert }^2_2=\bs x\cdot\bs x\).)

Two norms \({\lVert \cdot\rVert }_a\) and \({\lVert \cdot\rVert }_b\) on the same vector space \(\mathcal V\) are equivalent if there exist constants \(c,C>0\) such that \(c{\lVert x\rVert }_a\leq {\lVert x\rVert }_b\leq C{\lVert x\rVert }_a\) for any \(x\in \mathcal V\). Equivalent norms define the same convergent sequences and the same open and closed sets.

Theorem 2.29. Any two norms on \(\R^k\) are equivalent.

Exercise 2.11. Prove Theorem 2.29.

Hence one can speak of convergence and continuity in \(\R^k\) without specifying which norm is used, and \(\R^k\) is a Banach space with respect to any norm. From now on, \({\lvert \bs x\rvert }\) denotes a fixed norm of \(\bs x\in\R^k\).

2.3.5The space \(\mathcal C(I;\R^k)\)

Let \(I\) be a closed bounded interval, and let \(\mathcal C(I;\R^k)\) be the vector space of continuous functions \(\bs x\colon I\longrightarrow\R^k\) with pointwise operations. Define \[ {\lVert \bs x\rVert }_\infty=\max_{t\in I}{\lvert \bs x(t)\rvert }. \] For \(k=1\) this is the metric \(\varrho_\infty\) of Example 2.16.

Corollary 2.30. \((\mathcal C(I;\R^k),{\lVert \cdot\rVert }_\infty)\) is a Banach space.

Proof. The proofs of Lemmas 2.20 and 2.23 work word for word if the absolute value is replaced by the norm \({\lvert \cdot\rvert }\) in \(\R^k\) and the completeness of \(\R\) is replaced by the completeness of \(\R^k\). ■

Corollary 2.31. Let \(\bs x_0\in\R^k\) and \(b>0\). The set \[ \mathcal B=\left\{\bs x\in\mathcal C(I;\R^k)\colon {\lvert \bs x(t)-\bs x_0\rvert }\leq b\text{ for all }t\in I\right\} \] with the distance \(\varrho(\bs x,\bs y)={\lVert \bs x-\bs y\rVert }_\infty\) is a complete metric space.

Proof. By Corollary 2.30 and Lemma 2.25 it is enough to show that \(\mathcal B\) is closed. If \(\bs x_n\in\mathcal B\) and \(\bs x_n\to\bs x\), then for each \(t\in I\) I have \(\bs x_n(t)\to\bs x(t)\), and by the continuity of the norm \({\lvert \bs x(t)-\bs x_0\rvert }=\lim{\lvert \bs x_n(t)-\bs x_0\rvert }\leq b\), i.e., \(\bs x\in\mathcal B\). ■

Note that \(\mathcal B\) is not a vector space, but it is a complete metric space, which is all I need for the contraction mapping principle below.

2.3.6Contraction mapping principle

Consider a metric space \((\mathcal M,\varrho)\).

Definition 2.32. A point \(\hat x\in \mathcal M\) is called a fixed point of a mapping \(T\colon \mathcal M\longrightarrow \mathcal M\) if \[ \hat x=T\hat x. \]

Definition 2.33. A mapping \(T\colon \mathcal M\longrightarrow \mathcal M\) of a metric space \((\mathcal M,\varrho)\) is called a contraction if there exists a number \(q\), \(0\leq q<1\), such that the inequality4 \[ \varrho(Tx_1,Tx_2)\leq q\,\varrho(x_1,x_2) \] holds for any points \(x_1,x_2\in \mathcal M\).

Note in particular that the contraction mapping is continuous.

Theorem 2.34 (Banach’s fixed point theorem1

  1. Stefan Banach proved this theorem in his doctoral thesis in 1922. This theorem is also called the contraction mapping principle.↩︎

). Let \((\mathcal M,\varrho)\) be a complete metric space, and let \(T\colon \mathcal M\longrightarrow \mathcal M\) be a contraction. Then \(T\) has a unique fixed point \(\hat x\in \mathcal M\).

Proof. \( \)

\((i)\) Uniqueness. Let \(\hat x\) and \(\hat y\) be such that \(T\hat x=\hat x\) and \(T\hat y=\hat y\). Then, by \[ \varrho(\hat x,\hat y)=\varrho(T\hat x,T\hat y)\leq q\,\varrho(\hat x,\hat y) \] and \(q<1\), I have that \(\varrho(\hat x,\hat y)=0\), i.e., \(\hat x=\hat y\).

\((ii)\) Existence. Consider a sequence \((x_n)_{n=0}^\infty\) defined as \[ x_{n+1}=Tx_n,\quad x_0\in \mathcal M. \] I estimate \[ \varrho(x_{n+1},x_{n})=\varrho(Tx_n,Tx_{n-1})\leq q\,\varrho(x_{n},x_{n-1})\leq\ldots\leq q^n\varrho(x_1,x_0). \] Now, for \(m\geq n\), \[ \varrho(x_m,x_n)\leq \sum_{j=n}^{m-1}\varrho(x_{j+1},x_j)\leq \sum_{j=n}^{m-1}q^j\varrho(x_1,x_0)\leq \frac{q^n}{1-q}\,\varrho(x_1,x_0). \] Since \(q^n\to 0\), the sequence \((x_n)_{n=0}^\infty\) is fundamental, and since \(\mathcal M\) is complete, there is the limit \(x_n\to \hat x\in \mathcal M\).

Since a contraction is continuous, I can exchange the operations of limit and mapping (Lemma 2.19), i.e., \[ x_{n+1}=Tx_n\implies \lim_{n\to \infty }x_{n+1}=T\lim_{n\to\infty} x_n\implies \hat x=T\hat x, \] which proves that \(\hat x\) is indeed a unique fixed point of \(T\). ■

Letting \(m\to\infty\) in the last estimate, I also get how fast the iterations converge: \[ \varrho(x_n,\hat x)\leq \frac{q^n}{1-q}\,\varrho(x_1,x_0). \]

Remark 2.35. Now it should be clear what the exact strategy for my ultimate goal is. I have the integral equation (2.6) and need to make its right-hand side a contraction. More precisely, I need a complete metric space (which quite obviously should be a set of the form \(\mathcal B\) in Corollary 2.31, a closed subset of \(\mathcal C(I;\R^k)\) with the uniform distance \(\varrho_\infty\)), I need a mapping \(T\colon \bs x\mapsto \bs x_0+\int_{t_0}^t\bs f(\tau,\bs x(\tau))\D\tau\), and I need to choose the interval \(I\) and the radius \(b\) such that \(T\) maps \(\mathcal B\) into itself and is a contraction on it. This will guarantee both existence and uniqueness of the solution to the initial value problem (2.4), (2.5).
